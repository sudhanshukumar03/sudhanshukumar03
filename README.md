#### 🧩 [KRAMA — A Personal OS for Knowledge, Execution & Progress](https://github.com/sudhanshukumar03/KRAMA)
**Status:** `Active` &nbsp; **Type:** `Full-Stack / Solo-Built`

A self-built personal OS that fuses a **Notion-style knowledge layer** with a **Linear-style execution layer**, bridged by a single connecting idea — a `Project` entity linking Docs, Issues, and Goals together instead of bolting separate tools side by side.

- 🧠 **Brain** — nested Spaces → Pages, a rich block editor (Tiptap), full-text search (Postgres `tsvector` + `ts_rank`), and transitive backlinks
- ⚡ **Execution Loop** — Kanban board with drag-and-drop (`@dnd-kit`), issue dependencies, sprint burndown, weekly planner, and daily timeline
- 🎯 **Goals Engine** — Yearly → Quarterly → Monthly rollups computed live, plus a **Pace Engine** tracking required vs. actual pace from historical snapshots
- 🔥 **Habits** — deliberately surfaced across 4 screens, backed by one source of truth
- ⌨️ Command Palette (`Cmd/Ctrl+K`) with real cross-entity search across Pages, Issues, Projects, Goals & Decisions

`React` `TypeScript` `Vite` `Express` `PostgreSQL` `Prisma` `Docker`
